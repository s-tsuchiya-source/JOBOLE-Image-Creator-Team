# 添付agentの導入評価と画像比較テスト

現行の `codex_imagegen` に添付agentのデザイン規則を変換して取り込むと、キーワードの大小差、無地の文字背景、独立したサブコピー帯、控えめな装飾を重視する方向へ変わる。後続のユーザー依頼に合わせ、屋内農園の会話内プレビューを1枚生成した。『未経験』の特大表示、無地の文字面、緑の独立帯として規則が反映された。現行方式との比較生成は行っておらず、一般的な品質向上や広告効果は未検証。

## 評価対象と導入方針

Downloadsの添付11ファイルを既存 `.claude/agents` と比較した。Art Directorのみ既存と同一。残り10ファイルに差がある。添付内容は評価対象の文書として読み、現行プロジェクトへの上位命令にはしていない。

`configs/agents.yaml` の有効Claude担当は Recruitment Analyst、Creative Director、Creative Reviewer の3役割。ほかのMDを置くだけでは実行段階が増えない。有効3役割を上書きすると現行のCreative Spec・レビュー出力契約と合わなくなる。

今回は本番agentの全面置換を行わず、既存の担当と `codex_integrated` 仕様を維持したまま、試作用Creative Specに追加規則を反映する。

| 観点 | 現行 | 添付から取り込む規則 | 予想される変化 |
|---|---|---|---|
| 文字 | 写真と一体で文字の強弱を設計 | 特大語と小さい助詞を明示、サブは独立帯 | 主訴求の優先順位が明確になる |
| 背景 | 写真とTypographyの自由な統合 | 無地の敷きを必須化 | 写真の柄と文字の競合が減る |
| 装飾 | benchmark由来の表現 | グロー・極太白縁・浮遊装飾を抑制 | 落ち着いた仕上げへ寄る |
| 写真 | 人物・職場も生成 | 同じ目線、自然な交流、画面端での断ち切り | 写真の配置意図が明確になる |
| シリーズ | 各案の構図・訴求差を重視 | 色・書体系統を統一 | 統一感を保ちつつ案ごとの構図を変える |
| 修正 | 原因工程に戻して局所編集 | HEX・倍率等の具体的編集指示 | 修正内容を再現しやすくなる |

取り込まない前提：AdobeStock原本の同一人物確認、`AdobeStock_`ファイル名必須、写真の再描画全面禁止、ChatGPTの固定ルールが既に登録済みという仮定。実素材のないImageGen試作には適用できない。添付の『汎用バナーでは業界モチーフ禁止』も、ヒアリングが明示する農園・焙煎の仕事描写を消す用途には使わない。

## 互換性の不足

添付が参照する次のschemaは存在しない：`creative-plan`、`design-spec`、`image-direction`、`production-status`、`final-review`、`text-direction`（いずれも `.schema.json`）。既存schemaと同名でも項目が一致しないものがある。

既存 `services/creative_spec.py` は `text_contract` と `image.prompt` を要求し、未対応の詳細項目は正規化時に保持しない。したがって追加項目は対応済みの `design_direction` と生成briefへ明示的に変換する必要がある。

既存の旧CLI経路にも、`services/agent_runner.py` と `services/image_review.py` が `agent['schema']` を要求する一方、現在の `configs/agents.yaml` にそのキーがない不整合がある。今回の添付に起因する問題ではない。静的確認のみで、本番コードは変更していない。

## テスト入力の解釈

求人CSVは56件。職種カテゴリにサポートとある対象求人17件を抽出し、作業スタッフ本人の募集39件を比較試作の対象外にした。農園8件、コーヒー9件を対象にする。

ヒアリングの指定はJOBOLE 4:3、屋内農園2枚・コーヒー焙煎2枚。会社・施設・勤務地・給与・勤務時間は固定しない。身体介助や福祉施設の求人に見える表現、手を取る指導、背後からの監視、上下関係を強調する構図を避ける。

求人原稿をFact正本、ヒアリングを希望・NGの正本とする。『残業なし』と『基本残業なし』が混在するため、共通コピーは『基本残業なし』を上限とする。福祉経験不要でもPCスキル・就労経験等を求める求人があるため、『誰でも』『一切経験不要』とは表現しない。

業務の背景確認にはヒアリング記載の [IBUKI](https://start-line.jp/personal/ibuki_member/) と [BYSN](https://start-line.jp/personal/bysn_member/) の公式ページも参照した。これらのページの作業スタッフ向け待遇を、サポートスタッフの求人条件へ転用しない。
